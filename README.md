## Run Locally

**Prerequisites:**  Node.js


1. Install dependencies:
   `npm install`
2. Set `VITE_SUPABASE_URL` and `VITE_SUPABASE_ANON_KEY` in [.env.local](.env.local) to your Supabase URL and anonymous/public Key
3. Run the app:
   `npm run dev`

Prompt/folder deletion and UploadThing image cleanup require the server setup
described in [Görsel temizleme kurulumu](docs/image-cleanup.md).
